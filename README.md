# Descripción del proyecto
TiendaPy es una aplicación de consola desarrollada en Python que permite a los propietarios de tiendas de barrio gestionar su inventario, procesar ventas, controlar el stock mínimo, conservar la información de forma persistente y generar reportes diarios. La aplicación está diseñada para ser fácil de usar, incluso para personas sin formación técnica, y se enfoca en resolver problemas comunes como desabastecimiento inesperado, errores de cálculo, productos sin rotación, pérdida de información y compras ineficientes.
